# Referências

Cada referência foi conferida numa fonte real: Crossref, resolvedor de DOI, página da editora, USGS Publications Warehouse, Open Library ou página do órgão. Um PDF só é incluído **quando a licença permite redistribuir** (CC BY 4.0 ou domínio público dos EUA). As demais referências aparecem com DOI ou link.

Os documentos em [docs/](../docs/) citam pelo sistema autor-data da ABNT NBR 10520:2023, e cada um traz no fim a própria lista de referências. Aqui as referências estão no formato da ABNT NBR 6023:2018, agrupadas por tema, com a citação correspondente e o uso que o projeto faz de cada obra. Os títulos ficam no idioma original.
